① GitHub Token（必填）

需要一个有 gist 权限 的 Personal Access Token（免费，存在你自己的浏览器账号里）。
生成入口：点我直达 GitHub Token 生成页（已勾选 gist）
精确模式：Settings → Developer settings → Personal access tokens → Generate new token（classic），只勾 gist 一项即可。

② Gist（选已有或新建）

建议专门建一个私有 Gist 用来存书签，别跟代码混用。
Gist 里的文件名，默认 BookmarkHub。⚠️ 改名后缀要保留 .json 或纯文本均可，原版 BookmarkHub 的数据也能直接读。

数据格式说明（与原版 BookmarkHub 兼容） 
{
  "version": "1.0.0",
  "createDate": 1699999999999,
  "browser": "Mozilla/5.0 ...",
  "bookmarks": [
    {
      "title": "ToolbarFolder",
      "children": [
        { "title": "GitHub", "url": "https://github.com" },
        { "title": "工作", "children": [ ... ] }
      ]
    },
    { "title": "UnfiledFolder", "children": [...] },
    { "title": "MobileFolder", "children": [...] }
  ]
}
根文件夹命名约定：ToolbarFolder=书签栏 / UnfiledFolder=其他书签 / MobileFolder=手机书签 / MenuFolder=Firefox菜单栏。
原版 BookmarkHub 写入 Gist 的数据就是长这样，所以两边可以混用、互相同步。

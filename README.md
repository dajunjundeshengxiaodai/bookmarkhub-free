# 免费版BookmarkHub — 使用说明

原版 BookmarkHub（Chrome 商店版）收费且一安装就自动更新，本项目是完全等价的免费替代：

- **原理**：书签树 → JSON → 存到你**自己的 GitHub Gist**（私密），下载即恢复。没有第三方服务器，数据 100% 在你手里
- **数据格式与原版 BookmarkHub 完全兼容**：原版写进 Gist 的书签数据，本插件能直接读；反之亦然，可以混用
- **无自动更新**：manifest 不带 `update_url`，本地开发者模式加载，永不被商店覆盖

## 安装（Chrome / Edge，开发者模式）

1. 浏览器打开 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」→ 选本目录（`bookmarkhub-free`）
4. 固定到工具栏即可使用

> Chrome 每次启动可能提示「请关闭开发者模式弹窗」，点叉即可，不影响使用。

## 首次配置

1. 插件弹出页点「⚙ 设置」
2. **Token**：点说明里的直达链接，在 GitHub 上生成一个只勾 `gist` 权限的 classic Token，粘进输入框 → 「校验 Token」
3. **Gist**：没建过的点「一键新建私有 Gist」（自动填 ID）；已有书签 Gist（比如原版建的）点「拉取我的 Gist 列表」→ 点「使用」选定
4. 「保存设置」

## 日常使用

- 弹出窗口：**↑ 上传**（本地→云端）/ **↓ 下载**（云端→本地，覆盖本地，有二次确认）
- **⟳ 刷新**：本地数重新统计；云端数真拉 Gist 实际文件算（配置完没同步过也能看云端有没有数据）
- 书签有改动时图标显示红色 `!` 角标，提醒你没同步
- 「清空本地」会把本地书签全删（保留四个根文件夹），有二次确认
- 「云端书签」计数：同步过 = 上次同步时的数量；没同步过点 ⟳ 刷新可查实际值

## 跨浏览器

支持 Chrome / Edge / Firefox（Firefox 需要 manifest 适配，当前包是 MV3 Chrome 版）。书签数据里根文件夹统一命名：

| Gist 里的名字 | Chrome | Firefox |
|---|---|---|
| ToolbarFolder | 书签栏 | 书签工具栏 |
| UnfiledFolder | 其他书签 | 其他书签 |
| MobileFolder | 移动设备书签 | 移动书签 |
| MenuFolder | （并入其他书签） | 书签菜单 |

下载恢复时自动映射回当前浏览器对应的根文件夹。

## 文件清单

| 文件 | 作用 |
|---|---|
| `manifest.json` | MV3 清单，无 `update_url`（关键：不自动更新） |
| `background.js` | 核心逻辑：Gist API + 书签树序列化/恢复 + 角标 + 通知 |
| `popup.html/js` | 弹出窗口：上传/下载/清空/计数 |
| `options.html/js` | 设置页：Token 校验、Gist 列表选择、一键新建 Gist |
| `icons/` | 图标（沿用原版图标） |

## 与原版差异

| | 原版 BookmarkHub | 免费版 |
|---|---|---|
| 价格 | 收费 | 免费 |
| 自动更新 | 一装就更新 | 无（本地加载） |
| 代码量 | React 打包 140KB 压缩 | ~30KB 可读源码 |
| 数据格式 | — | 完全兼容 |
| 附加能力 | — | Token 校验 / Gist 列表选择 / 一键新建 Gist / 下载二次确认 |
